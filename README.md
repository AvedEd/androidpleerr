# androidpleerr

Android-плеер для стриминга торрентов через **TorrServer** + встроенный **IPTV**-плеер.

## Возможности
- Добавление торрентов по magnet-ссылке или ссылке на `.torrent`
- Стриминг видео прямо во время закачки, без ожидания полной загрузки
- Список серий для торрентов с несколькими видеофайлами (сериалы, сезоны)
- Автопереход к следующей серии (включается в настройках)
- Живой показ скорости закачки и числа пиров во время просмотра
- Выбор озвучки и субтитров прямо в плеере (названия студий — если они зашиты в самом файле)
- IPTV: загрузка M3U-плейлиста, поиск по каналам, избранное, офлайн-кэш плейлиста
- Сохранение позиции просмотра — плеер сам предложит продолжить с места остановки
- Проверка обновлений приложения по кнопке (через GitHub Releases)

## Как это работает
Приложение — это просто пульт для твоего **TorrServer** (открытый сервер, раздающий торренты по HTTP). Сам плеер ничего не ищет и не качает — адрес сервера и ссылку на IPTV-плейлист указываешь в настройках.

## Сборка APK
Проект собирается автоматически через **GitHub Actions** — при пуше в ветку `main` или вручную через вкладку **Actions → Build APK → Run workflow**. Готовый APK появляется в разделе **Artifacts** этого запуска и во вкладке **Releases**.

## Настройка внутри приложения
1. **Настройки** → укажи адрес TorrServer (`host:port`) и, если нужно, ссылку на M3U-плейлист.
2. На главном экране вставляй magnet-ссылки — приложение добавит торрент и покажет список файлов/серий.

## Структура проекта
app/src/main/java/com/androidpleerr/app/
├── data/ — модели + клиент TorrServer API
├── iptv/ — парсер M3U-плейлистов
├── prefs/ — настройки (SharedPreferences)
├── ui/ — экраны и адаптеры списков
└── update/ — проверка обновлений через GitHub Releases
