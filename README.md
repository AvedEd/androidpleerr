# androidpleerr

Объединённый плеер, собранный из лучших фич твоих двух APK (оба — клиенты **TorrServer** с похожей структурой). Это не пересборка старого кода, а чистый новый проект на Kotlin с тем же набором возможностей — так надёжнее и проще поддерживать.

## Что взято из первого APK (app-release.apk)
- **IPTV**: загрузка M3U-плейлиста, список каналов с поиском, воспроизведение.
- Более новый Media3 ExoPlayer.

## Что взято из второго APK (app-release-2.apk)
- **Список серий** для торрентов с несколькими видеофайлами (сериал/сезон) — выбор эпизода прямо в плеере.
- **Живая статистика** во время просмотра: скорость загрузки и число пиров, обновляется каждые 2 секунды.
- Более продвинутая проверка обновлений с загрузкой APK.

## Общее (было в обоих)
- Подключение к своему серверу **TorrServer** (host:port), добавление magnet/torrent-ссылок.
- Сохранение позиции воспроизведения, настройки плеера.
- Проверка обновлений через **GitHub Releases** — то есть само приложение сможет проверять, не собрал ли GitHub Actions новую версию, и предлагать установить её.

## Важно про сам плеер
Это клиент для **TorrServer** (github.com/YouROK/TorrServe) — свободного опенсорсного сервера, который раздаёт торренты по HTTP. Само приложение не качает и не ищет пиратский контент — это просто плеер/пульт для твоего сервера, плюс IPTV-плеер для M3U-плейлистов. Что через него смотреть — решаешь ты сам.

## Как собрать APK через iPhone + GitHub (без компьютера)

### Шаг 1. Создай репозиторий на GitHub
1. В Safari (или в приложении **GitHub**) зайди на github.com, войди в аккаунт.
2. Нажми **New repository**, назови `androidpleerr`, сделай его приватным или публичным — на твой выбор.
3. Ничего не инициализируй (без README) — просто создай пустой репозиторий.

### Шаг 2. Загрузи файлы проекта
Самый простой способ с iPhone — через сайт GitHub:
1. Открой свежесозданный репозиторий в Safari.
2. Нажми **Add file → Upload files**.
3. Загрузи содержимое папки `androidpleerr` целиком (можно по частям — сначала корневые файлы `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `.gitignore`, `README.md`, затем папку `app/`, затем `.github/workflows/build.yml`).
   - Если загрузка папками неудобна через Safari — установи бесплатное приложение **Working Copy** (Git-клиент для iOS), склонируй пустой репозиторий, скопируй туда файлы через приложение Files, и запушь одним коммитом. Это надёжнее, чем поштучная загрузка через браузер.
4. Сделай commit прямо в ветку `main`.

### Шаг 3. GitHub Actions соберёт APK автоматически
- Как только файлы окажутся в ветке `main`, запустится workflow `.github/workflows/build.yml`.
- Открой вкладку **Actions** в репозитории — увидишь запущенный процесс "Build APK".
- Через 3–5 минут сборка завершится и появится:
  - **Artifact** `androidpleerr-debug-apk` (можно скачать прямо со страницы Actions → Summary → Artifacts).
  - Новый **Release** с прикреплённым `app-debug.apk` (вкладка **Releases**).

### Шаг 4. Установи APK на телефон
1. Скачай `app-debug.apk` на iPhone… стоп — это Android-приложение, устанавливать его нужно на **Android**-устройство, не на iPhone. iPhone тут используется только как «пульт управления» GitHub — сама сборка и установка происходят на Android-устройстве.
2. На Android-телефоне открой ссылку на Release (её можно переслать себе, например, через Telegram) и скачай `app-debug.apk`.
3. Разреши установку из неизвестных источников, установи APK.

### Шаг 5 (необязательно). Включи автообновление внутри приложения
В `app/build.gradle.kts` найди строку:
```kotlin
buildConfigField("String", "UPDATE_REPO", "\"\"")
```
и впиши туда свой репозиторий, например:
```kotlin
buildConfigField("String", "UPDATE_REPO", "\"твой_логин/androidpleerr\"")
```
Закоммить изменение — приложение сможет само проверять новые Release-сборки и предлагать установку.

## Настройка внутри приложения
1. Открой **Настройки** → укажи адрес своего TorrServer (например `192.168.1.10:8090`) и, если нужно, ссылку на M3U-плейлист для IPTV.
2. Нажми «Проверить соединение», чтобы убедиться, что сервер доступен.
3. На главном экране вставляй magnet-ссылки — приложение добавит торрент на сервер и покажет список файлов/серий для воспроизведения.

## Структура проекта
```
app/src/main/java/com/androidpleerr/app/
├── data/         — модели + TorrServer API-клиент (Retrofit)
├── iptv/         — парсер M3U-плейлистов
├── prefs/        — настройки (SharedPreferences)
├── ui/           — экраны: Main, Player, Iptv, Settings + адаптеры списков
└── update/       — проверка обновлений через GitHub Releases
```

## Известные ограничения (что можно доделать)
- Автопереход к следующей серии по окончании файла — сделан как точка расширения (`playNextEpisode()` в `PlayerActivity.kt`), сейчас не переключает индекс автоматически.
- Подпись release-сборки (сейчас собирается debug-APK, подписанный автоматическим debug-ключом — этого достаточно для личного использования, но не для публикации в Google Play).
- Иконка — простой плейсхолдер, можно заменить на свою через `app/src/main/res/mipmap-*`.
