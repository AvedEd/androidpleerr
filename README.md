# androidpleerr

Android-плеер для стриминга торрентов через **TorrServer** + встроенный **IPTV**-плеер.

## Возможности

**Торренты**
- Добавление по magnet-ссылке или ссылке на `.torrent`
- Стриминг видео прямо во время закачки, без ожидания полной загрузки
- Список серий для многофайловых торрентов, с подсветкой текущей серии и читаемыми названиями (S01E05 и т.п.)
- Автопереход к следующей серии
- Живой показ скорости закачки и числа пиров
- «Продолжить просмотр» — на главном экране показывается недосмотренное, с прогресс-баром

**Плеер**
- Экран не гаснет во время просмотра
- Жесты: двойной тап — перемотка с анимацией; свайп слева — яркость, справа — громкость
- Выбор озвучки и субтитров прямо в плеере — с названиями из самого файла (студия озвучки и т.п.)
- Автовыбор предпочитаемого языка озвучки/субтитров
- Сохранение позиции просмотра
- Работает как системный видеоплеер — появляется в списке «Открыть с помощью», в том числе при выборе торрента для просмотра из **Lampa**

**IPTV**
- Несколько M3U-плейлистов одновременно, объединяются в один список
- Группировка каналов по категориям
- Избранное и поиск по каналам
- Офлайн-кэш — список каналов доступен даже без интернета

**Прочее**
- Проверка обновлений приложения только по кнопке (через GitHub Releases), никаких фоновых проверок

## Как это работает

Приложение — это пульт для твоего **TorrServer** (открытый сервер, раздающий торренты по HTTP). Само оно ничего не ищет и не качает — адрес сервера и IPTV-плейлисты указываются в настройках.

## Сборка APK

Проект собирается автоматически через **GitHub Actions** — при пуше в `main` или вручную через **Actions → Build APK → Run workflow**. Готовый APK — в разделе **Artifacts** этого запуска и во вкладке **Releases**.

## Настройка внутри приложения

1. **Настройки** → адрес TorrServer (`host:port`), плейлисты IPTV (по одному на строку), предпочитаемый язык озвучки/субтитров
2. На главном экране — magnet-ссылки для добавления торрентов

## Структура проекта
app/src/main/java/com/androidpleerr/app/
├── data/ — модели + клиент TorrServer API
├── iptv/ — парсер M3U-плейлистов
├── prefs/ — настройки (SharedPreferences)
├── ui/ — экраны и адаптеры списков
└── update/ — проверка обновлений через GitHub Releases
